# Crew Lookahead — notes for Claude

Crew/manpower planning app for Tim's low-voltage crew (Tim is the lead; there is also a super and crew).
Live at https://timrwillis.github.io/crew-lookahead (GitHub Pages from `main` of timrwillis/crew-lookahead, public repo).

## Files
- `index.html` — the whole app (vanilla JS in one IIFE, ~4k lines). No build step.
- `firestore.rules` — Firebase security rules. Tim pastes these into Firebase Console → Firestore → Rules by hand after every change. Always tell him when rules changed.
- `firebase-config.js` — public Firebase web config (project `workflow-98636`).
- `sw.js` — service worker (notifications, install).
- `practice.js` — Practice board: loaded only with `?practice=1` (`&as=crew` = tech view, `&as=new` = brand-new user with no company). Swaps `window.firebase` for an in-browser fake saved in localStorage `cl_practice_db_v3`, seeded with a made-up company `po`/crew `pc` and crew/jobs (public file: never real names or sites). `window.CL_PRACTICE` {reset,exit,switchTo}; notifications and the setup popup are off in practice. Entry: avatar sheet → 🧪 Practice board (managers). If you add Firestore calls the fake doesn't support, add them there.
- `import-data.json` — only `hoursPlan` now. Never put names or site info here: it's public.

## Companies and crews (Nov 2026, for selling)
- Data layer: `RAWDB` = real Firestore; `db = scopeDb(RAWDB)` prefixes every path with `BASE` (`orgs/<o>/crews/<c>/`, or "" for the original top-level "legacy" board). `feeds` stay global (`GLOBAL_COLS`). Use `RAWDB` only for org/crew/users docs.
- `orgs/<o>` {name, ownerUid}; `orgs/<o>/crews/<c>` {name, by, moving}; a crew holds a full board (team/config, team/roles, team/crew, people, jobs…). `users/<uid>` {boards:{"o~c":{org,crew,at}}, cur}.
- `pickBoard()` in `startSession`: `?join=o~c` invite adds the board; else users.cur; else legacy if the top-level board exists and hasn't moved (`team/config.movedTo` → everyone is sent to the new board); else `noBoard` → `renderWelcome` (start a company). `orgOwner` = owner on every crew (`isOwner` includes it).
- Avatar sheet `boardsBlock()`: switch board (`switchBoard` reloads), `inviteSheet` (link; joiners land in Waiting), `addCrewSheet` (org owner), `moveSheet` (legacy owner copies `MOVE_COLS` + team docs into a new company with crew `moving:true`, then sets `movedTo`). Rules: nested `match /orgs/{o}/crews/{c}` copy of the board rules with `c`-prefixed function names, plus `/{col}/{id}` create while `moving()`.
- User-facing text says `TIM()` (the board owner's first name, else "your lead"), never a hard-coded "Tim".

## App basics
- `h(tag, attrs, ...kids)` builds DOM (no html attr). State in `S` (Firestore onSnapshot per collection). `render()` / `schedule()`; sheets via `openSheet(title, fields, onSave)` / `openView(title, nodes)` / `closeSheet()`; `liveSheet` redraws an open sheet.
- Roles: owner/lead/super = `MGR()`; crew; helpers with `until` expiry; pending until approved. `myId` = auth uid, `myTech()` = linked crew record.
- Crew can only write `jobs.marks` (+updatedAt), so all crew state lives in marks: cable step marks `marks[cid][sid]`, task state `marks._task_<id>`, cable checklist `marks[cid]._ck`, whole-job complete `marks._job`.
- Cables: `job.cables`, `job.steps`; scan steps `scan_cable/scan_src/scan_dst` (or the job's own matching steps via `scanLike`). Scanning: `scanCode` (phones: camera photo first, live scanner backup; laptops: handheld/upload only), `decodePhoto`, `applyCodesToCk(jid,cid,codes,photo,hint,{by,batch,keepRepeat})`, `uploadScans` for photos sent by others.
- Time off: crew only load their own (`where uid==me`), entries carry `uid` (synced by managers' apps).
- Live Google Sheet: `feeds/<random key>` doc with csv/history/summary + `data` JSON; Apps Script from `feedScript(j)` builds a Cables list + a tab per cable.
- Check list items 2-5 are derived in `ckOf` from sign-offs (2+3 Ported, 4 VFL/Tested, 5 = lead/super who recorded them once 1-4 done), marked `fromSteps`, never saved (`saveCk` strips them); `ckRaw` = stored only.
- Roll call: `attendance/<date>` {marks:{techId:{s:"here"|"out",at,by}}}, managers only (own listener `startAtt`, not in `S`, so missing rules don't break the board). `outOn`/`awayOn` feed `dayInfo` (marked-out people count as off). UI: `rollBar`/`attBtns` on Home → Manpower, `attHistory` view.
- Job notes: `marks._note_<id>` {text,sev(urgent/fyi/suggest/other),cab,sys,pull,cable,photos,fix:{status open/fixing/fixed,to,…},doneAt}; `notesSheet(jid,pre)`; photos + .txt records go to Documents folder "Notes" (files carry `noteId`).
- Crew home (`renderMyWork`): main card = current task; `myWorkList` (via `workFooter`) lists every open task they're on in any job (`myOpenWork`), each opens `myTaskSheet` to check off cables / mark done / scan.
- Pulls from prints (`printPulls`, button in `pullBuilder`): Tim marks pulls in Bluebeam (Polygon/Cloud/Rect/Ellipse/Pen loop = devices inside; Polyline/Line = devices near it), Comment like "1.14 BMS Row 12"; color blue/red/green = BMS/Cameras/WAPs as a fallback. PDF read in-browser only (pdf.js 3.11.174 for text+render, pdf-lib for /Annots incl. Subj/Contents), never uploaded. Tags matched via `ppTagIndex` (cable ID, port part, `from`, label lines; plain numbers skipped). Sets `c.pull=pullKey(rack,type,name)`.
- Quick tasks: `kind:"quick"`, `quick.pri` (critical/high/normal/low), `quick.client`.
- Navigation (Nov 2026 revamp): bottom bar shows 4 groups from `NAVGROUPS()` (managers: Today / Jobs[jobs,tasks,board=Schedule,material] / Crew[crew,off] / Inbox[chat,messages]; crew: My work / Time off / Material / Inbox). Old `.tab[data-t]` buttons stay in the DOM hidden (their SVGs are cloned as group icons). `groupStrip()` draws the underline sub-tabs at the top of a group; `lastIn` remembers the last screen per group. `setTab`/hash routing is unchanged. Header `#themeBtn` toggles light/dark; avatar `#acctBtn` → `acctSheet()` (alerts, device setup, profile, `themePicker()` Light/Dark/Auto saved as `cl_theme`, sign out). Light-only color overrides must stay inside a light media query or `[data-theme="light"]` or dark mode text goes dark. Task editor in `jobForm`: tasks default to "Can start anytime" (`t.after` picker hidden behind `.tlink`), per-task `tools` + job `tools` (`toolsEditor`, shown to crew by `toolsLine`); `toolsEditor` is a type-to-search tag picker backed by `toolLib()` (team/crew `tools`, `toolsHidden`, defaults, tools used on jobs); step tool kits in team/crew `stepTools` keyed by `stepKey()` (Pulled→pull…), edited in `toolLibSheet()` (Material → Tool list, or + menu) and per step in `cableEditor` (Cables & steps: each step card has a 🧰 button), shown to crew in `toolsLine`; Step-named tasks (Pull/Dress/Terminate/Label/VFL/Test) on cable jobs are auto-converted by `maybeFixStepTasks` → `fixStepTasks` (managers only, saves a version first): tasks removed, Cat6 steps normalized to CAB_STEPS_DEFAULT with marks copied from old combo steps, task tools seeded into `stepTools`. Task editor on cable jobs only offers "+ Add task". `maybeScopeTasks` links "1.14 BMS"-style tasks to `scope:{rack,type}` and sets `p.cab` on phases named after a rack. `stepMatrix` (Tasks view: steps by cabinet, and by system inside an open cabinet card) and `stepBars` (crew task card + task sheet) show each step done/total per cabinet+system; cells open `cableTracker` filtered to that cabinet/system. Tasks can have a `due` date (task editor 📅 Due; crew card shows a due chip; used in `crewBrief` and suggestions). Cat6 standard steps = `CAB_STEPS_DEFAULT` Pull → Dress → Terminate → Label → Test. New phases default to not waiting. Floating `#fab` → `quickAdd()` (flag, scan, new job, quick task, note, call in, recharge, time off, tech, material). Cable history timeline in `cableTracker` = `.ctl`. Quick check-off (`quickCheck(jid,tid)`): the task's cables grouped by pull/row (`qcGroups`, `qcPull`), one tap per step marks the whole group (`setMarks`), tap a done one twice to undo; opened from the crew task card "✓ Check off work", `stepBars`, task sheet and + menu. `checkoffNudge()` on crew My work + one notification per day within 75 min of shift end if they checked nothing off today. My day rows warn "No check-offs since…" (`lastMarkAt`) after 2 days. Duplicate job (`duplicateJob`) also from + → Copy a past job. Feedback: messages `kind:"feedback"` {cat,text,where,fileId,ua,w} (excluded from `isNote`); `feedbackForm()` from + menu and avatar sheet, `feedbackList()` for managers (avatar → Crew feedback) with "Copy all for Claude". Avoid class name `full` on buttons inside grids (global `.full{grid-column:1/-1}`). `cableEditor` cable list is grouped: cabinet cards → system chips with counts (`drawCables`/`grpOf`); a chip opens `cableGroupSheet(rack,type)`, a compact spreadsheet popup (edit name/pull/ft, add with Enter, pick rows → set pull, move system, remove) that edits the draft `cables` array (saved with the sheet). Sheet Save/Cancel bar is sticky (`.sheet .form>.actions`).
- My day layout (Nov 24 bento): `renderDay` = glance tiles `.gltiles/.glt` (`tile()`: flags, huddle, here, need crew, meetings, plan ahead, wrap-up; tap opens the full section via `daySheet(title,build)` which sets liveSheet) + `.bento` grid (big `bcard` "Who's on what" with compact `assignRow` rows that open the task's job; side column: roll call (only if unchecked, `rollList(d,true,5)`), Today meetings `meetList`, Heads up `.hline` links). - My day (managers' Today default, `homeSeg="day"`, `renderDay`) sections (originally flow cards): 1 huddle (`huddleCard`/`huddleSheet` → `attendance/<date>.huddle` {photo,plan,here,posted}: roll call, whiteboard photo of the PTP/ORM (they write it on a dry-erase board; photo goes to files folder "PTP · ORM", `shareBoard` sends it to safety), `crewBrief(d)` = who's on what / due / coming up, optionally posted to crew chat; no prompting after shift start + 90 min; supers (role boss) only see it read-only), 2 roll call (`rollBar`+`rollList`), 3 assignments (`liveTargets`, free = `dayInfo().idle` (excludes `isLeadTech`: leads/foremen/supers never count as free), `suggestAssign(d)`/`suggBox` greedy suggestions: people on tasks that are done (100%) or almost done (≥85%, extra hands) move to the next best task (same job/cabinet preferred, done tasks never targets), then free people (no one on it, job short, priority, due soon); `taskProg(j,t)` = % of the task's cable-steps done; `moveMany(pairs)` moves several people one at a time waiting for each save (always use it for multi-moves); `pickTech` is multi-select; Metrics (Crew → Stats, `renderMetrics`, `computeMetrics(days)` memoized): 1 unit = one cable through one step; a day's units on a task are split across that task's crew that day (crewOn), leads excluded; per tech units/day, by system/step/rack; `jobForecast(j,M)` = pace (last 10 days), left, finish vs due, people needed. Auto-fill (`autoFill(d)`/`autoFillSheet`, ⚡ button in My day Assignments): `positionsFor` gives spots per task from remaining work, job techs needed and forecast; keeps current crew, then fills the emptiest task first with the best fit (personal rate on that system vs crew avg, knows that cabinet, already on it); applies via `moveMany`. Plan ahead shows jobs behind schedule. Crew needs per task: `t.need` {roleKey:count} (CREW_ROLES lift/spotter/puller/stager/laborer/term/tester/labeler/fork, custom `c:Name`; roles with `skill` regex need that cert from tech skills, e.g. Lift / MEWP); edited with `needEditor` in the task editor (👥 Crew needed), templates in team/crew `crewKits` [{name,need}]; `needTotal`/`needText`/`needGap`; positions never below the minimum, auto-fill fills minimums first and prefers certified people, suggestions favor short tasks, My day rows show 👥 have/need + ⚠ gaps; crew task card shows the crew makeup. `pickTarget`/`pickTech` → `moveTech`; out-but-assigned warnings), 4 meetings & reminders (`remForm` → messages with `kind` meeting/reminder, `remindOn`, `remindAt` HH:MM; `dueRem` and `checkAlerts` respect the time; 60s interval re-checks), 5 plan ahead (next workday staffing + `prepItems` for jobs starting in 14 days), Calendar (`homeSeg="cal"`, `renderCal`): month grid with dots + selected day + next 2 weeks from `calItems(d)` (messages meeting/reminder/due with `remindAt`/`dur`, task `due`, job start/end, time off, holidays). Outlook/phone calendars via .ics files (`icsEvent`/`sendICS`: share sheet on phones, download elsewhere) — no live Outlook sync (needs IT-approved Microsoft app). `remForm(kind)` kinds meeting/reminder/due, optional auto .ics. Timed alerts only fire within 60 min after `remindAt`. 6 wrap-up (`wrapSheet` → `attendance/<date>.wrap`, share summary, tomorrow's plan becomes a 6 AM reminder next workday; `daySummary` counts step marks made today).

- Plan / Gantt (Jobs → Schedule → Plan, managers, `mode="plan"`, `renderGantt`): jobs as bars (conf color, % fill, 👷 techs), forecast late tail `.gt-ghost` from `jobForecast`, task due markers, expand a job (`ganttOpen`) for task rows, zoom `ganttWeeks` 4/8/12/26 (`cl_gweeks`), window starts the week before `cursor`. Crew-needed lane `ganttNeed(d,M)` = firm (likely+locked techs) + extra (late jobs' tail and forecast people above plan) vs `dayInfo().avail`; tap a day → Day view. Outside schedule: `gcImportSheet` reads CSV (Task Name/Start/Finish; MS Project, P6, Smartsheet, Excel) or MS Project XML on device (`parseSchedule`, `toISO`), optional keyword filter, saved as team/crew `gcSched` [{name,start,end}] + `gcName/gcFilter/gcAt` (≤400 lines). Tiles reuse `tile()`.
- Wide layout: `.wrap.wide` on every tab but chat; crew techs list is a 2-col `.crewgrid`; Hours = 2 columns (`.hrsgrid`, standard hours left). Live status: a `team/config` listener with includeMetadataChanges sets "Live" (fake Firestores accept an options first arg).
- All hands (Nov 2026): `j.push` {taskId,start,until(""|date = today only),at,by,snap:{techId:[[jobId,taskId]…]}} on the job, one active at a time (`activePush()`). `pushSheet(j,t)` (🚨 in Today's priorities, live-board ⋯ menu) sends everyone here (`pushPool`, leads excluded, all pre-checked) in one save per job via `moveSet(moves,extra)` (batch version of moveTech; use it for group moves). `snap` = where each person was (`placesOf`), so `endPush` (banner End, task Done, or `checkPushExpiry` the next workday for today-only) sends them back (`placeTarget`, free if that work is gone); `pushLog` keeps history. `pushBanner` on My day / live board: names tap → `pickTarget` (has "↩ Back to their regular work" / "🚨 To all hands"), "＋ N not on it" → `pushAdd`. Other tasks show "⏸ Paused" via `pausedFor`. During a push, suggestions/auto-fill only point at the push target. Crew My work shows a banner.
- Today's priorities (`prioCard` in My day Assignments): `prioScore` ranks open targets with reasons (job priority, due, forecast behind, tasks waiting on it, crew size/lifts, % done); the lead's ▲▼ order is saved as team/crew `order` ["jobId|taskId"] and always wins (`prioList`); `orderBonus` feeds suggestAssign and autoFill.
- Tech pick-ups (Nov 2026): when a tech finishes (task Done → `whatsNext`, or whole job → finish form) or has nothing assigned, `picksView` shows `nextPicks(me,d)` (built on `prioList`: all hands first, lead's order, then no one on it / short of crew) with "▶ Start this" + other open tasks. Crew can't write assignments, so `claimTask` writes `marks._claim_<techId>` {taskId,at,by} and alerts leads; `claimOf`/`claimersOf` make `membersOn`/`taskFor`/`assignOn` treat it as their assignment that day; a lead's app (`applyClaims`, on My day / live board render) turns claims into real crewLog moves via `moveSet` and deletes the marks. Open tasks on a job a tech marked complete (`jobFin`) still count.
